# OCR-Assisted PDF Renamer Tool

A browser-based PDF utility designed to reduce repetitive document-processing work through OCR-assisted name extraction, batch file handling, editable filenames, and ZIP export.

This project was developed as a practical tool for records and document management workflows.

## Key Features

- OCR-assisted name extraction using Tesseract.js
- Batch PDF folder upload
- In-browser PDF preview
- Editable extracted filenames before download
- Optional Date, File Name, and Attachment fields
- Enable or disable individual filename components
- Attachment numbering support
- Select All, Deselect All, and Clear All controls
- Sort files by name, size, or upload date
- PDF file validation
- Maximum 50 MB file-size validation
- ZIP generation with progress feedback
- PDF splitter with multiple splitting modes
- Visual PDF rotation and orientation
- Bulk PDF merging by folder or subfolder
